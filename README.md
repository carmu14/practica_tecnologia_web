# practica_tecnologia_web
Desarrollo de un sitio web utilizando HTML5

Objetivo

Aplicar los conocimientos adquiridos en las Unidades 2 y 3 de la guía didáctica mediante el diseño e implementación de un sitio web estático que evidencie el uso correcto de los principales elementos de HTML5, la organización de contenidos, la navegación entre páginas y las buenas prácticas de desarrollo web.

Instrucciones

Después de revisar las Unidades 2 y 3 de la guía didáctica, desarrolle un sitio web cuyo tema sea:

Impacto de las Tecnologías Web en la Sociedad y los Negocios

El sitio web deberá evidenciar la aplicación de los conceptos estudiados durante el primer bimestre.

Al finalizar la actividad, entregue un archivo comprimido (.zip) que contenga:

Sitio web
Informe técnico de implementación (PDF).
Enlace público del repositorio en GitHub o Bitbucket.
Suba únicamente el archivo comprimido en el espacio habilitado para la tarea en el Entorno Virtual de Aprendizaje.

Requerimientos técnicos

El sitio web deberá cumplir con los siguientes requisitos:

Estructura del sitio
Crear una página principal denominada index.html.
Crear al menos tres páginas secundarias relacionadas con la temática.
Organizar adecuadamente los archivos del proyecto utilizando carpetas (por ejemplo: css, images, videos, pages, etc.).
Estructura semántica
Utilizar correctamente las etiquetas semánticas de HTML5:

<header>
<nav>
<main>
<section>
<article>
<aside>
<footer>
Estas deberán emplearse de forma adecuada para organizar el contenido.

Navegación
Incorporar un menú de navegación presente en todas las páginas.
Todas las páginas deberán encontrarse correctamente enlazadas mediante rutas relativas.
Organización del contenido
El sitio deberá incluir:

Encabezados jerárquicos (h1–h6).
Párrafos.
Listas ordenadas y/o desordenadas.
Al menos una tabla con información relacionada con la temática.
Recursos multimedia
Incorporar:

Mínimo cinco imágenes pertinentes.
Al menos un video relacionado con el tema (embebido o almacenado localmente).
Todos los recursos deberán visualizarse correctamente.

Formulario
Implementar un formulario de contacto que incluya como mínimo:

Nombre
Correo electrónico
Asunto
Mensaje
Botón de envío
Utilice apropiadamente los elementos:

<form>
<label>
<input>
<textarea>
<button>
Buenas prácticas
El código deberá presentar:

Sangría e indentación correcta.
Nombres de archivos claros.
Uso de rutas relativas.
Ausencia de enlaces rotos
Comentarios cuando sean necesarios.
No debería tener error, use el validador de la W3C
